## 版本说明

### 版本号规则
遵循 [语义化版本](https://semver.org/lang/zh-CN/) 规范：`主版本号.次版本号.修订号`

- **主版本号**：不兼容的 API 修改
- **次版本号**：向下兼容的功能性新增
- **修订号**：向下兼容的问题修正

### 变更类型
- `🎉` - 重大发布
- `✨` - 新功能
- `🔧` - 修复
- `📚` - 文档
- `♻️` - 重构
- `🎨` - 样式/UI
- `⚡` - 性能优化
