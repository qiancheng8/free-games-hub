# 多平台免费游戏聚合站 - 需求文档

## 1. 项目背景

### 1.1 现状分析
当前项目仅专注于 Epic Games 商店的每周免费游戏展示，功能单一，覆盖面有限。

### 1.2 市场需求
- 用户希望在一个平台上查看所有主流游戏平台的免费游戏信息
- 减少用户在多个平台间切换的时间成本
- 提供更全面的历史记录和追踪功能

### 1.3 参考网站
- **IsThereAnyDeal**: 多平台免费游戏聚合，分类清晰
- **PinoGamer**: 详细的游戏信息展示，表格形式清晰
- **GG.Deals**: 游戏新闻和限时优惠整合

## 2. 产品目标

### 2.1 核心目标
将现有的单平台 Epic 免费游戏展示，扩展为多平台免费游戏聚合平台。

### 2.2 具体目标
- 支持至少 5 个主流游戏平台
- 实时更新各平台免费游戏信息
- 提供友好的用户体验和强大的筛选功能
- 保留完整的历史记录

## 4. 数据需求

### 4.1 数据来源
- Epic Games Store API
- Steam Web API
- Itch.io RSS/API
- IndieGala 网页抓取
- GOG 网页抓取

### 4.2 数据结构
每个游戏条目应包含：
- 游戏 ID（唯一标识）
- 游戏名称
- 游戏描述
- 游戏封面图
- 原价
- 免费开始时间
- 免费结束时间
- 平台标识
- 领取链接
- 抓取时间

### 4.3 数据存储
- 当前免费游戏：`data/games.json`
- 历史免费游戏：`data/history.json`
- 按平台分类的缓存文件

## 5. 用户界面需求

### 5.1 首页
- 轮播展示当前热门免费游戏
- 当前进行中的免费游戏卡片列表
- 即将免费游戏预览
- 平台筛选栏
- 搜索框

### 5.2 游戏详情页
- 游戏大图
- 详细描述
- 原价与免费信息对比
- 倒计时显示
- 平台标识
- 立即领取按钮
- 相关游戏推荐

### 5.3 历史记录页
- 按时间倒序排列
- 支持按平台、时间范围筛选
- 表格或卡片视图切换

### 5.4 即将免费页
- 展示未来将要免费的游戏
- 按开始时间排序
- 倒计时显示
